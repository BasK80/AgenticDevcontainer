# pick-model — bundled research asset

| File | What it establishes |
| --- | --- |
| `taxonomy-and-routing.md` | The task taxonomy and the routing policy `pick-model` implements. |

`../REFERENCE.md` is deliberately written as *method* — how to decide — and
defers the *why* to this document. Read it before changing a routing default,
a task type or the consent gate, so you're overruling a reasoned position
rather than an arbitrary one. Nothing here is needed to *run* the skill:
`REFERENCE.md` plus `../seed/*.json` are self-contained.

Dates and figures inside are snapshots from the original investigation — trust
`../seed/*.json` and live re-verification over anything stated in prose.
